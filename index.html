Integración con Google Sheets

Conecta este CRM a una hoja de Google mediante un Apps Script Web App. Cada guardado local se sincroniza automáticamente (o al pulsar "Sincronizar") con tu hoja, y puedes traer los datos existentes de la hoja al CRM en cualquier momento.

Código de Apps Script

1) Crea una hoja de Google nueva → Extensiones → Apps Script.
2) Borra el contenido y pega el código de abajo.
3) Implementar → Nueva implementación → Tipo: Aplicación web → Ejecutar como: Yo → Quién tiene acceso: Cualquiera.
4) Copia la URL del Web App y pégala en Configuración → "URL del Web App".
